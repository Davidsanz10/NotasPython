Es una estructura de datos para almacenar valores de diferente tipo similiar a las [[02. Listas]] pero con la diferencia que las tuplas son inmutables, es decir no se modifican luego de su creación.
-  No permiten añadir, eliminar  ni mover elementos.
- Sí permiten extraer porciones, pero el resultado es una nueva tupla.
- No permiten busquedas ( no por index)
- Si se puede comprobar si un elemento pertenece a una tupla

### Ventajas
- Más rápidas
- Menos espacio (mayor optimización)
- formatean Strings ()
- Pueden usarse como claves en un diccionario. (las listas no)
Sintaxis 
	nombreTupla = (elem1, elem2, elem3)..

``` python
misDatos=("David", 30,1,2000)

print (misDatos)
```

 ``` bash
('David',30,1,2000)
```
**Convertir tupla a  [[02. Listas]]** con el metodo List () 

``` python
misDatos=("David", 30,1,2000)
misDatosLista = Lista(misDatos)
print (misDatosLista)
```

 ``` bash

```

Convertir una lista a Tupla
``` python
misDatos=["David", 30,1,2000]
misDatosTupla = tuple(misDatos)
print (misDatosTupla)
```

 ``` bash
['David',30,1,2000]
```

Comprobar si un elemento está en su interior 
``` python
misDatos=["David", 30,1,2000]
misDatosTupla = tuple(misDatos)
print ("David" in misDatosTupla)
```

Devuelva un Booleano

 ``` bash
True
```

Para ello se puede hacer cuantas veces se encuentra el elemento en una Tupla, se hace uso del método **Count**

``` python
misDatos=["David", 30,1,2000,"David"]
misDatosTupla = tuple(misDatos)
print (misDatosTupla.count("David"))
```
Devuelva un valor

 ``` bash
2
```

saber el longitud de una tupla con el método len()
``` python
misDatos=["David", 30,1,2000,"David"]
misDatosTupla = tuple(misDatos)
print (len(misDatosTupla))
```
Devuelva un valor

 ``` bash
2
```

