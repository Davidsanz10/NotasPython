es una estructuras de datos para almacenar información similar a [[02. Listas]] y a [[03. Tuplas]]  pueden ser de diferentes tipos inclusive listas y otros diccionarios, pero con la diferencia que permite almacenar información en que los datos se asocian a una clave, por ello se crea una asociación de tipo **clave:valor** para cada elemento almacenado.

Es como una tabla, pero los elementos no están ordenados, aunque el orden es indiferente a la hora de almacenar información en un diccionario.

| orden | Clave    | Valor  |
| ----- | -------- | ------ |
| 2     | España   | Madrid |
| 1     | Peru     | Lima   |
| 3     | Colombia | Bogotá |
| 5     | Francia  | París  |
| 4     | Ecuador  | Quito  |
Ejemplo de código en python
``` python
Capitales = {"Peru":"Lima", "España":"Madrid","Francia":"París"}
	print(capitales)
```
Clave: Peru 
Valor: Lima
Retorna las capitales

 ``` bash
{'Peru':'Lima', 'España':"Madrid','Francia':'París'}
```

podemos **agregar valor al final** simplemente llamando al diccionario con la clave y asignado el valor.
``` python
capitales = {"Peru":"Lima","España":"Madrid","Francia":"París"}
	capitales["Colombia"]= "Bogota"
	print(capitales)
```
retorna el diccionario con el nuevo valor:

 ``` bash
{'Peru':'Lima', 'España':'Madrid','Francia':'París', 'Colombia':'Bogotá'}
```

si quieres **modificar un valor** en especifico sería similar solo llamando la clave, y cambiar el valor.

``` python
capitales = {"Peru":"Lima", "España":"Madrid","Francia":"París"}
	capitales["Colombia"]= "Bogota"
capitales["España":"Barcelona"]=
	print(capitales)
```
retorna el diccionario con el nuevo valor:

 ``` bash
{'Peru':'Lima','España':'Barcelona','Francia':'París', 'Colombia':'Bogotá'}
```

si queremos **eliminar** tenemos que hacer uso de del

``` python
capitales = "Peru":"Lima","España":"Madrid","Francia":"París"}
	capitales["Colombia"]= "Bogota" capitales["España":"Barcelona"]=
print(capitales) #antes de eliminar
del capitales["España"];
	print(capitales)
	#despúes de eliminar
```

retorna el diccionario con el nuevo valor:

 ``` bash
{'Peru':'Lima', 'España':'Barcelona','Francia':'París','Colombia':'Bogotá'}

{'Peru':'Lima','Francia':'París','Colombia':'Bogotá'}
```

tener en cuenta que se pueden almacenar de diferentes tipos de datos.
```python
datos ={"Peru":"Lima",23:"Davidevs","Manzanas":5}
```

Ya que Python es de tipado dinámico, es decir que no necesitas especificar el tipo y luego puedes guardar el tipo de datos que desee; que a contraste de tipado estático (cómo en Java) donde debes definir a priori cual será el tipo de datos, no se puede cambiar ni mezclarlo.
